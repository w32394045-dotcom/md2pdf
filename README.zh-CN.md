# md2pdf — 离线单文件 Markdown → PDF 排版工具

[English](README.md) · **简体中文**

一个 HTML 文件、零依赖、纯前端。打开 `index.html` 即可使用，**不联网也能跑**。

## 在线使用

**主站：https://md2pdf.xszx.cc.cd** —— 平时用这个就行。

| 入口 | 地址 | 什么时候用 |
|---|---|---|
| **主站** | **https://md2pdf.xszx.cc.cd** | 默认用这个（自建域名，Cloudflare 部署） |
| 备用 1 | https://md2pdf.w32394045.workers.dev | 同一个 Cloudflare Worker 的原生地址，域名解析出问题时用 |
| 备用 2 | https://w32394045-dotcom.github.io/md2pdf/ | GitHub Pages，Cloudflare 整体不可用时用 |

三处跑的是同一份 `index.html`（内容逐字节一致），功能完全相同。数据只存在你自己的浏览器里，
所以换地址打开时设置不会跟过去、历史文件也不共通——认准主站用就好。

## 功能

- **Markdown 渲染**：标题、列表、表格、引用、脚注、任务列表、删除线、高亮，代码块语法高亮，中文软换行
- **打印排版**：A4 / Letter / A5，页边距可选；「打印 / 存 PDF」→ 浏览器打印界面 → 另存为 PDF
  - 产出是**矢量文字 PDF**：文字可选中、可搜索、放大不糊，不是截图
- **数学公式**：内联 **Temml 0.14**（MIT）把 LaTeX 转成 MathML
  - 覆盖 amsmath / amssymb 的绝大多数命令：`\lesssim` `\geqslant` `\twoheadrightarrow` `\boxed` `\cancel` `\overrightarrow` `\operatorname` `\color` `\begin{aligned}` …
  - 输出仍是 MathML，靠浏览器原生排版，**不引入任何字体文件**；打印/导出照样是矢量文字
  - Temml 也认不出的冷门写法会退回内置的简易解析器，最差是原样显示命令名，不会整段丢内容
- **化学式**：`\ce{H2SO4}`、`\ce{2H2 + O2 -> 2H2O}`、`\ce{N2(g) + 3H2(g) <=> 2NH3(g)}`、`\ce{2H2O2 ->[MnO2] 2H2O + O2}`、`\ce{CuSO4.5H2O}`、`\ce{SO4^2-}`；单位 `\pu{1.0e-3 mol/L}`。自带轻量转换，不需要 mhchem
- **目录**：可开关，并可限定收录到 H1 / H1–H2 / H1–H3 / 全部
- **主题色**：**7 套预设**点一下就换，或色环取色（可拖到任意位置，不限于小点）、直接输入 `#RRGGBB`、明度滑块；另有「↺ 重置主题色」。它统一控制链接、引用块竖杠与底纹、表头底色、标题下划线、表格边框、分隔线、`==高亮==` 底色、任务框勾选，以及界面自身的按钮/焦点框；打印时自动换算成"打印安全色"（过亮的颜色会压暗，避免印出来看不见）
- **页面背景**：可以上传一张图，也可以从历史缩略图里挑一张；内置毛玻璃裁剪器，A4 / 正方形 / 圆形三种取景，拖动移动、滚轮或双指缩放、按屏幕像素比出图，另有「保持原图」跳过裁剪。两个滑杆分别控制背景图本身和内容底色的不透明度（表格、代码块、引用块、目录这类带底色的元素）。打印时把背景画成固定覆盖层（Chromium 会把固定定位元素逐页重复绘制）——记得在打印界面勾上「背景图形」。图片只存本机，不上传
- **从图片取色**：默认从当前背景图取色，也能临时换一张图；十字线和 13×13 像素的放大镜跟着指针走，Chromium 里还能用系统取色器吸屏幕任意位置（其他浏览器按钮置灰）。最近用过的 24 个颜色排成格子，点一下换回来，右上角 ✕ 删除，刷新后还在
- **渲染型围栏**：`svg` / `css` / `html` / `render` 围栏里的内容会被渲染，而不是当代码显示；围栏标成 `text` 则保留代码原样
- **内嵌 SVG**：正文里直接写 `<svg>`，打印保持真矢量（脚本、事件属性、外链都会被清掉）
- **制作者信息与页面信息栏**：可选头像 + 一行文字，放在文档顶部或底部；页面底部信息栏显示工具名和仓库链接，可以关掉。样式写在文档样式里，预览、打印、导出三处一致
- **脚注排法**：三选一——文末（默认）、就近（注释跟在引用它的那一段后面，打印时同页可见）、就近 + 文末汇总
- **本地图片不再断图**：打开 `.md` 时一起选中的图片会存进本机数据库，刷新页面或从历史里重新打开，正文里的图都还在
- **JSON 自定义扩展**：一份 JSON 可以改解析前的全文替换（`preProcess`）、加行内语法和新围栏（`customSyntax`）、在顶栏加一个插入文字的按钮（`uiInjection`）、加只作用于文档的样式（`cssInjection`）。产出和自定义 CSS 走跟渲染型围栏同一套安全过滤；JSON 写坏了整份禁用并明确报错，不会半套生效；扩展存本机，刷新后还在
- **设置页**：五个 Tab——外观 / 背景与图片 / 智能扩展 / 打印与导出 / 数据与字体。设置自动存本地数据库，重开页面还在，可「恢复全部默认设置」；「数据与字体」里还有字体导入和字体库。无痕模式拿不到数据库时界面会明确提示，而不是假装存上了
- **设置导出与导入**：把设置和扩展一起打包成一个 JSON 文件，换设备时导入即可；文件里不含背景图、头像、正文图片和字体库
- **导出**：可导出独立 HTML 文件（字体、图片和页面背景都内嵌），也可只存 `.md`
- **历史**：顶栏「🗂 历史」列出写过的文档（标题 / 最后修改 / 字数 / 占用），可打开、单条删除、清空（均二次确认）。打字停下约 2.6 秒自动更新当前文档的快照，最多保留 50 条，超出自动丢最旧的；全部存在浏览器本地 IndexedDB，不上传
- **界面语言（7 种）**：简体中文 · 繁體中文 · 日本語 · 한국어 · Deutsch · Français · English。
  首次打开按浏览器语言自动匹配，顶栏「🌐」下拉框随时切换；**内置示例文档也跟着语言变**
  （每种语言各备一份，不是机翻拼接）。
  切换语言后默认**整页自动刷新**（最稳：所有文字、菜单、示例按新语言重建），并把示例文档一起换掉；
  这两项都能在设置里关掉。主题色的 7 个预设色名也跟着翻译。

## 用法

1. 用 Chrome / Edge 打开 `index.html`
2. 点「打开」选一个 `.md`（有本地图片就把 `.md` 和图片一起选中；图片会存进本机数据库，刷新后不会再断）
3. 预览无问题后点「打印 / 存 PDF」，在系统打印界面把目标选成「另存为 PDF」

## 安全边界

渲染型围栏与原始 HTML 都会经过过滤：`<script>`、`onclick` 等事件属性、`javascript:` / `data:text/html` 伪协议、外链 `url()`、`@import` 都会被移除，避免载入外部资源或执行脚本。JSON 扩展走同一套过滤：它生成的 HTML 一样过消毒，模板占位符按「数据」插入（转义后拼入，不会变成标签/属性），自定义 CSS 只进文档样式，`@import`、`javascript:` 和外链 `url()` 同样被去掉。仅用于可信来源的文档排版。

工具自身运行时不请求任何网络资源：Markdown 解析、公式转换、字体、设置与历史全部在本机完成
（Temml、KaTeX 之类的库都**已内联进这一个文件**，不是 CDN 引用）。
但文档里**引用的远程图片**仍会由浏览器加载——不可信的 `.md` 请断网打开，或先把外链图片去掉。
