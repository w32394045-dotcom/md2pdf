字体

去哪找免费字体
  • Google Fonts —— 全开源。中文挑 Noto Sans SC / Noto Serif SC，在字体页右上角点「Download family」拿 .ttf
  • 思源黑体 / 思源宋体 —— Adobe 官方仓库，OFL 协议，字最全，最稳妥
  • 猫啃网 —— 专收中文免费商用字体，每款都标了授权来源，中文字体首选
  • 100font —— 免注册直接下，中英日韩都有，按授权类型分了类
  • Font Squirrel —— 西文为主，每款都标了能不能商用

「免费下载」≠「免费商用」。导入的字体在「导出 HTML」时会一起打包进文件里， 等于你在二次分发它——对外发布的文档请只挑 OFL / MIT / Apache 这类明确允许再分发的。 另外很多免费中文字体只做了常用 3500 字，冷僻字会掉回系统字体、看着像串了字号。

公式

导出 PDF：点「打印 / 存 PDF」，在系统打印界面把目标选成「另存为 PDF」再保存。
（「存 .md」存的是 Markdown 源码；网页自身写不出 PDF 文件，这条路必须走系统打印。）
这样出来的是真正的矢量文字 PDF——文字可选中、可搜索、可复制，放大不糊，不是截图。
想要页码，在打印界面里把「页眉和页脚」打开即可（浏览器会自动加页码）。
文档里有本地图片？点「打开」时把 .md 和图片一起选中，程序会按文件名自动对应。
